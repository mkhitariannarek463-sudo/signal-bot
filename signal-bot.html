      Համեմատում է Binance, Bybit, OKX և Gate.io բորսաները, եռանկյուն արբիտրաժը Binance-ում և funding-ի տարբերությունները։ Բոլոր թվերը միջնորդավճարից հետո են։

      Telegram՝ սիգնալները գալիս են հեռախոսիդ (համակարգչում բոտը կարող է աշխատել 24/7)։ Լիկվիդացիաներ՝ Binance Futures forceOrder stream, կասկադներ և կլաստերներ, որոնք մտնում են Order Flow score-ի մեջ։ Կորելյացիա՝ 1ժ եկամտաբերությունների Pearson կորելյացիա, Risk Control-ը արգելում է չափից շատ նույն ուղղությամբ կորելացված դիրքեր։ Backtest՝ մինչև 10,000 մոմ պատմություն, հաշվարկը առանձին thread-ում (Web Worker)։ Օրացույց՝ ForexFactory-ի High-impact USD/EUR իրադարձությունները ավտոմատ։

      🤖 Ավտո սիգնալներ

      Ընտրված թայմֆրեյմներով (5ր–4ժ) ստուգում է բոլոր ակտիվները (1/5/15 րոպեն մեկ)։ Ռեժիմը փոխում է շեմը՝ Զգուշավոր 7.5, Նորմալ 6.5, Ակտիվ 5.5։ «Պատրաստվիր» ցանկը ցույց է տալիս շեմին մոտ կամ արգելված setup-ները։ Յուրաքանչյուր BUY/SELL անցնում է նույն վերլուծությունը և Risk Control-ը, ցույց է տրվում մեկ անգամ, ունի ձայնային ծանուցում և քայլ առ քայլ հրահանգ (քանակ, Stop, TP)։ Ամեն 15վ ստուգվում է՝ դեռ վավեր է, ուշ է, թե Stop/TP-ն արդեն հասել է։ Բաց դիրքերի համար ցույց է տալիս, թե ինչ անել հիմա։

      Market Momentum Detection

      ROC(10) և դրա արագացումը (ROC − ROC 3 մոմ առաջ), MACD histogram, Breakout/Breakdown 20 մոմի գագաթ/հատակ + ծավալ ≥1.5σ, Momentum Reversal (ուժեղ շարժում → acceleration շրջվում է + RSI), Volume Spike (log-ծավալի z-score), Buying/Selling Pressure (Binance-ի taker buy ծավալից delta 20 մոմում)։ Չափազանց երկար իմպուլսը տույժ է ստանում (chasing)։

      Real-Time Order Flow

      aggTrade-ից՝ ագրեսիվ գնորդներ/վաճառողներ (market order-ի կողմը), 60վ imbalance, live CVD, խոշոր պատվերներ (≥20× մեդիան notional), Absorption (մի կողմի ագրեսիվ հոսք > 60%, ծավալը միջինից 1.5× բարձր, բայց գինը չի շարժվում)։ depth20-ից՝ Bid/Ask pressure և Order Book imbalance։

      Volatility Analysis

      ATR 14, ATR 5/50 հարաբերակցություն (>1.3 expansion, <0.75 compression), Bollinger Bands, %B, լայնության percentile, squeeze release, Sudden Price Movement (մոմ > 3 ATR, live՝ 10վ-ում > 1.5 ATR(1m))։ Live էջը ասում է՝ շուկան հարմար է արագ գործարքների համար, թե ոչ։

      Arbitrage Detection

      Cross-exchange՝ ամենաէժան ask և ամենաթանկ bid 4 բորսայում, net = gross − 2× fee։ Triangular՝ USDT→A→X→USDT և հակառակը BTC/ETH/BNB-ով, 3× taker fee, առավելագույն չափը top-of-book-ով։ Funding arbitrage՝ long spot + short perp (կամ հակառակը), տարեկան եկամտաբերություն, 4 leg-ի ծախս և break-even funding-ների քանակ։ Փոխանցման ծախսերն ու ժամանակը ներառված չեն։

      Market Anomaly Detection

      Abnormal Volume (>4σ), Abnormal Price Move (եկամտաբերության >4σ), Flash Crash/Pump (>4 ATR և արագ վերադարձ), Sudden Liquidity Drop (order book-ի իրացվելիությունը < 50% միջինից), Spoofing-like Pattern (խոշոր «պատեր», որոնք անհետանում են <10վ-ում առանց կատարվելու, ≥3 անգամ 60վ-ում), Unusual Order Book Activity։ «high» մակարդակը արգելափակում է գործարքները։

      Smart Order Execution

      Market order-ի սիմուլյացիա order book-ի վրա (100 մակարդակ)՝ միջին գին, slippage bps, Partial Fill ռիսկ։ Maker vs Taker ծախս և խնայողությունը R-ով։ Առաջարկ՝ LIMIT (pullback), MARKET (իմպուլս), SPLIT (մեծ պատվեր), REDUCE, NO TRADE։ Order Cancellation կանոն և Dynamic Order Placement (limit՝ entry − 0.1 ATR)։

      Dynamic Exit Management

      ATR + կառուցվածքային SL, Partial TP 50% TP1-ում (1.5R), Break-Even, Chandelier Trailing Stop (2.5 ATR), Dynamic TP (ուժեղ իմպուլսի դեպքում TP2 մինչև 3.5R, թուլացող իմպուլսի դեպքում՝ վաղ փակում), Time-Based Exit (48 մոմ), Emergency Exit (անոմալիա կամ ուժեղ հակառակ սիգնալ)։

      Trade Opportunity Scoring

      Ամեն փաստարկ պատկանում է կատեգորիայի՝ Technical, Momentum, Volume, Order Flow, Volatility։ Risk Score (0–100) և Execution Cost (R) առանձին են. ≥70 risk կամ >0.4R ծախս → NO TRADE։ Վերջնական որոշում՝ BUY / SELL / NO TRADE։

      Real-Time Risk Control

      Անկախ շերտ, որը ստուգվում է ՎԵՐՋԻՆԸ և կարող է արգելել ցանկացած սիգնալ՝ Daily Loss Limit, Max Open Positions, Max Consecutive Losses, Cooldown վնասից հետո, Max Exposure, Emergency Stop (🛑 կոճակը վերևում), API Failure Protection (REST սխալներ, stale stream, latency), կրկնակի դիրքի պաշտպանություն, նորություններ։

      Adaptive Strategy Engine

      4 հաջորդական fold (Walk-Forward), պարամետրի ընտրություն առաջին 70%-ում և ստուգում վերջին 30%-ում (Out-of-Sample), արդյունքներ ըստ ռեժիմի, Concept Drift (վերջին գործարքներ vs պատմություն)։ Forward test՝ ամեն իրական սիգնալ գրանցվում և ավտոմատ հաշվարկվում է, համեմատվում backtest-ի EV-ի հետ։ Բոտը ինքը կանոնները չի փոխում։

      Low-Latency Infrastructure

      WebSocket streaming, event-driven մշակում (յուրաքանչյուր trade/depth իրադարձություն թարմացնում է վիճակը, իսկ որոշումը վերահաշվարկվում է ամեն 3վ), latency monitoring (Binance event time vs տեղական ժամ՝ server offset-ով ճշգրտված), reconnect exponential backoff-ով (1→2→4… 30վ), REST fallback, սիգնալների և դիրքերի կրկնօրինակների պաշտպանություն։ Asynchronous Python-ը բրաուզերում հնարավոր չէ — այստեղ նույն դերը կատարում է async/await JavaScript-ը։ 24/7 սերվերային տարբերակի համար հաջորդ քայլը Python asyncio + websockets է։

      1. Safari-ով բաց github.com և գրանցվիր (եթե հաշիվ չունես)։
      2. «+» → New repository → անուն՝ signal-bot → Public → Create։
      3. uploading an existing file → ընտրիր signal-bot.html-ը Files-ից → Commit changes։
      4. Settings → Pages → Branch՝ main / root → Save։
      5. 1–2 րոպեից բաց՝ https://ՔՈ-ԱՆՈՒՆԸ.github.io/signal-bot/signal-bot.html
      6. Safari → Share → Add to Home Screen՝ հավելվածի պես պատկերակ կունենաս։

      Համակարգչում ավելի պարզ է՝ ֆայլը կրկնակի սեղմիր, և այն կբացվի Chrome-ում։ Նոր տարբերակ ստանալու դեպքում պարզապես նորից վերբեռնիր ֆայլը նույն repo-ում։

      ⚠️ Սա ուսումնական գործիք է, ոչ թե ֆինանսական խորհուրդ։ Ոչ մի բոտ չի երաշխավորում շահույթ։ Սկզբում Forward Testing առնվազն 30–50 սիգնալ, և ռիսկի դիր միայն այն, ինչը կարող ես կորցնել։
