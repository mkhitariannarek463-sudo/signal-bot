# Signal Bot — Crypto Trading Signals (Armenian UI)

Browser-based crypto signal bot using live Binance data (REST + WebSocket).

- Technical analysis, market structure (BOS/CHoCH), supply/demand, volume profile
- Momentum, volatility and anomaly detection
- Real-time order flow: aggressive buyers/sellers, CVD, absorption, large orders
- Opportunity scoring → BUY / SELL / NO TRADE
- Independent real-time risk control (daily loss, exposure, cooldown, kill switch)
- Smart execution plan, dynamic exits, position manager
- Cross-exchange, triangular and funding-rate arbitrage monitor
- Backtest, walk-forward, out-of-sample, concept-drift monitoring

Educational tool, not financial advice. No orders are sent to any exchange.
